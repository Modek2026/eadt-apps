Comment installer

1. Appuie sur le bouton ci-dessus pour télécharger le fichier.

2. Une fois téléchargé, ouvre le fichier depuis tes notifications ou ton dossier "Téléchargements".

3. Si Android affiche "Installer des applications inconnues", appuie sur "Paramètres" puis autorise l'installation pour cette source.

4. Appuie sur "Installer".
